### 💡 Featured Projects

#### 🎯 [Sentiment Analysis & Spam Detection](https://github.com/Frenzy-codes/Sentiment-Analysis)
A machine learning pipeline that filters fake review spam using a Scikit-Learn Random Forest Classifier and classifies review sentiment using VADER.
* **Tech Stack**: Python (Flask, Streamlit), SQLite, Pandas, Scikit-Learn, Chart.js.
* **Database**: Local SQLite serverless architecture with automatic fallback data loading.

#### 🩸 [LifeFlow - Blood Donation & Emergency Routing](https://github.com/Frenzy-codes/LifeFlow)
An interactive emergency platform helping users connect with blood donors, locate blood banks, and host donation camps.
* **Tech Stack**: React 18, TypeScript, Supabase (with Row Level Security), TailwindCSS, OpenStreetMap (Leaflet).
* **Live Demo**: [https://life-flow-amber-ten.vercel.app/](https://life-flow-amber-ten.vercel.app/)
